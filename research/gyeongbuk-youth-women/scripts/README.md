# KOSIS Open API 연동 스크립트 사용법

경북 18개 시군 × 5세 연령구간(19-24/25-29/30-34/35-39) × 성별 인구 데이터를
일괄 조회해 CSV로 저장합니다. (2-1절 보완용)

## 1. 사전 준비

### 1-1. KOSIS Open API 인증키 발급

1. [KOSIS 국가통계포털](https://kosis.kr) 회원가입
2. 마이페이지 또는 "Open API" 메뉴 → "Open API 신청"
3. 승인까지 통상 1~2일 소요 (즉시 발급되지 않을 수 있음)

### 1-2. 통계표 코드(orgId/tblId) 및 분류코드 확인 — **가장 중요한 단계**

이 스크립트는 통계표 ID를 하드코딩하지 않습니다. KOSIS 통계표마다 분류
체계(연령 구간을 5세로 나누는지, 시군을 어떤 코드로 표현하는지 등)가
다르기 때문에, 잘못된 표 ID를 그대로 쓰면 겉보기엔 정상 작동하지만 실제로는
틀린 데이터를 수집하게 됩니다. 반드시 아래 순서로 직접 확인하세요.

1. KOSIS 홈페이지에서 통계표 검색: **"행정구역(시군구)별 5세별 주민등록인구현황"**
   (검색 결과 후보로 `orgId=101`, `tblId=DT_1B040A3`, "행정구역(시군구)별,
   성별 인구수" 통계표가 있으나, 이 표에 **5세 연령 분류가 포함되어 있는지는
   반드시 화면에서 직접 확인**하십시오. 포함되어 있지 않다면 "주민등록인구현황
   (연령별/성별)" 계열의 다른 표를 찾아야 합니다.)
2. 원하는 통계표를 연 뒤, 화면 상단의 **"Open API" 버튼**을 클릭하면 현재
   선택한 조건(지역/성별/연령)에 맞는 서비스 URL이 자동 생성됩니다.
3. 그 URL에서 `orgId`, `tblId`, `objL1`(지역코드), `objL2`(성별코드),
   `objL3`(연령코드), `itmId`(조회항목코드) 값을 그대로 복사해
   `kosis_config.json`에 채워 넣습니다.

### 1-3. 설정 파일 생성

```bash
cd research/gyeongbuk-youth-women/scripts
cp kosis_config.example.json kosis_config.json
# kosis_config.json을 열어 apiKey, orgId, tblId, objL1_map(18개 시군 코드),
# objL2_sex_map, objL3_age_map, itmId를 채워 넣는다.
```

`kosis_config.json`은 API 키를 포함하므로 `.gitignore`에 등록되어 있어
커밋되지 않습니다. 실수로 커밋하지 않도록 주의하세요.

## 2. 실행

```bash
python3 kosis_youth_population.py
```

정상 실행되면 `research/gyeongbuk-youth-women/data/gyeongbuk_youth_population_by_sex_age.csv`
파일이 생성됩니다. 열 구성: `시군, 성별, 연령구간, 시점, 인구수, 단위`

이 CSV를 2-1절([../docs/02-1_인구구조와_성별비교.md](../docs/02-1_인구구조와_성별비교.md))의
"미보완 사항"에 표로 정리해 반영합니다.

## 3. 자주 발생하는 오류

| 증상 | 원인 | 조치 |
|---|---|---|
| `[오류] 설정 파일이 없습니다` | `kosis_config.json` 미생성 | 1-3 단계 수행 |
| `[경고] KOSIS API 오류` | apiKey 미승인/만료, 또는 코드값 오류 | 인증키 승인 상태 확인, objL 코드값 재확인 |
| 결과는 나오는데 값이 이상함(0, 결측 등) | tblId가 5세 연령 분류를 포함하지 않는 표 | 1-2 단계에서 다른 통계표로 교체 |
| `수집된 데이터가 없습니다` | objL1_map(시군 코드)이 비어 있음 | kosis_config.json의 지역코드 매핑 완성 |
