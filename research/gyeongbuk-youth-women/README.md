## 연구 개요

**제목**: 경북 청년여성의 지역정주 기회구조 진단 및 AI 활용 정책지원 방안

**연구 성격**: 정책개입 효과를 검증하는 준실험 연구 → 현황을 진단하고 정책수요를
확인하여 정책대안을 설계하는 **진단형 정책연구**로 전환 (IRB 지적사항 반영,
2026-08 이전 확정)

**총괄 연구질문**: AI 시대에 경북 청년여성이 지역 안에서 성장하고 일하며 정주할
수 있도록, 경북도는 어떤 기회구조를 확대해야 하는가?

**하위 연구질문**
1. 경북 청년여성의 인구·이동·고용·생활여건은 청년남성과 비교해 어떤 특성을 보이는가?
2. 경북 청년여성의 지역정주를 어렵게 하는 주요 정주요건과 청년여성 특화 장벽은 무엇인가?
3. 경북 청년여성은 AI 활용을 학습·일·창업·관계·정책정보 접근의 기회로 인식하고 있는가?
4. 경북도는 청년여성의 지역정주 기회구조 확대를 위해 어떤 신규사업, 제도, 전달체계를 설계해야 하는가?

## 전체 목차

1. 연구 개요 및 정책문제 정의 (1·2절 완료 / 3~5절은 2장 확정 후 작성)
2. 경북 청년여성 현황 및 정책환경 분석 **← 현재 작성 중**
3. 선행연구 검토 및 분석틀
4. 경북 청년여성 지역정주 인식 및 정책수요 조사 (설문/SNS/FGI)
5. 경북 청년여성 지역정주 기회구조 진단
6. AI 기반 경북 청년여성 지역정주 정책대안
7. 실행전략 및 성과관리 체계

## 작업 3대 원칙

1. **통계 데이터 최대 활용**: 서술형 문장보다 표·수치 우선 배치, 모든 절에 최소
   1개 이상 통계표, 가능한 경우 성별·연령별·시군별 세분화
2. **전체 보고서 논리적 전개**: 2장 각 절의 "정책적 시사점"을 3장 분석틀·4장
   조사설계·6장 정책대안의 근거로 명시적 연결
3. **출처·참고문헌 명확화**: 모든 통계는 [출처, 발행연도, 조사기준일] 표 하단
   각주 병기, 참고문헌은 국내문헌/해외문헌/통계자료출처 3분류

## KOSIS Open API 연동 스크립트

경북 18개 시군 × 5세 연령구간(19-24/25-29/30-34/35-39) × 성별 인구 데이터를
일괄 조회하기 위한 스크립트입니다. 실행 전 준비사항과 사용법은
[scripts/README.md](scripts/README.md)를 참고하세요.

**선행조건**: KOSIS Open API 인증키 발급 필요 (KOSIS 홈페이지 회원가입 →
"Open API 신청", 통상 1~2일 소요). 발급 전에는 스크립트가 동작하지 않습니다.
